# やまだやAI（仮）

共用PCで使うAI Webアプリの試用版です。AIチャット、POP作成、画像作成・修正、文章作成をまとめています。

白いLiquid Glass UI、画面・カード・ダイアログのアニメーション、初期画面とAI処理中のスケルトン表示に対応。ログイン画面はありません。機能はサーバー側で基本4機能だけに制限し、業務システム・社内ファイル・顧客/従業員データへの接続や管理APIを持ちません。

初期試用は、ユーザーの指定どおり**このPCのブラウザから使う範囲**です。操作見本で基本4機能を確認でき、ブラウザから保存したA4/A3縦横4PDF・見本SVG・ダミーPNGのファイル検査も完了しました。クラウドや別PCへの配備は今回の完了条件に含めません。秘密を除いた[GitHubのソース](https://github.com/yuki2900221/yamadaya-ai)は公開済みです。

**実AIを使える試用版としての受入は未完了です。** 専用キーと合計10 USDの枠は準備済みですが、画像1件とWeb検索1件の計$0.40が課金未確定で、新規AI送信を停止しています。停止理由を画面に表示し、4機能の送信を無効にしています。入力の編集、下書き保存、保存済み結果の利用、課金しない操作見本の確認は継続できます。[試験結果と残件](docs/testing.md)を確認してください。

## 起動

Node.js 24.16以降の24系を使用します。

```sh
npm ci
npm test
npm run build
APP_MODE=demo npm start
```

`http://127.0.0.1:4176/` を開きます。`demo` は操作見本で、実AIの回答ではなく、課金もありません。実AIには別途サーバー専用キーと予算設定が必要です。[運用方法](docs/operations.md)を参照してください。

開発時は `APP_MODE=demo npm run dev` で `http://127.0.0.1:4174/` を開きます。共用PCへ渡す際は開発サーバーではなく、上記のビルド済み配信を使用してください。

## 試用上の扱い

- 接続は同じPCのループバックに限定。外部へそのまま公開する構成ではありません。
- 会話・結果・参照画像はサーバー/画面のメモリだけに保持。「利用を終了」または15分の無操作で利用を終了します。自分でダウンロードしたファイルは残ります。
- POPの下書きは利用者の操作でJSONに保存できます。写真は含みません。復元した情報から提案を再確認します。
- POPの用紙はA4/A3の縦横4種類で固定。未入力の特徴を防ぐため、提案の自動採用は入力済みの行と許可済みのデザイン文に制限します。自由なコピーは現在制限があります。
- 完成POPは画像です。PDFは指定用紙・5mm以上の余白で画像を配置します。画像内の文字や商品外観は人が確認する必要があり、選択可能な日本語テキストPDFではありません。
- API送信前に予算予約を記録します。二重送信を抑止し、通信断・課金不明は停止。自動再送や上位モデルへの切替はしません。
- 送信停止中はチャットのEnterキーでも入力を消去しません。サーバーがAPIへ送信する前に拒否したことを確認できる場合は、不要な結果確認待ちを残しません。送信後の結果不明は区別して保持します。
