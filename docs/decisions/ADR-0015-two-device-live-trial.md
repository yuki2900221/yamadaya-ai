# ADR-0015: 2台限定の実AI試用を先に使える状態へ進める

日付: 2026-10-20
状態: 採用（ユーザー承認済みの限定試用）
関連: REQ-003 / REQ-005 / REQ-010 / REQ-011 / REQ-012 / REQ-014、ADR-0014

## 判断

このMacと会社のWindows 11 / Chrome 1台で、個人ログインなしに基本4機能を実際に使うことを優先する。Vercel＋専用Supabase＋Cloudflare端末mTLSを継続し、追加の認証方式や将来機能の実装を試用開始の条件にしない。

元の合計10 USD、未確定3件の予約0.45 USD、2026-10-26 08:47:54 JSTの期限を維持する。旧ローカル実行元を停止・凍結し、同じ台帳metadataを専用trial領域へ一度だけ移す。新しい予算枠を作らず、元の未確定入力は再送しない。新たな未確定が出たら両端末の新規送信を止める。

ユーザーは、専用OpenAIキー、専用trial DBの期限付き最小権限loginと非公開画像保存、会社PC内の鍵に対する証明書1枚、および既存Vercelのサーバー専用設定への非公開保存を明示承認した。Windowsの秘密鍵を移送せず、会社PCに管理者のChatGPT/Codex・個人Googleアカウントを接続しない。公開CSRと公開証明書のみを会社の既存手段で受け渡す。

## 理由と代替案

モックの技術検証は進んだ一方、現場で実際に使い始めるまでの手間が目的を妨げていた。既に動作確認したアプリと認証境界を利用し、基本機能の実試用へ進む。認証を外した一般公開や社員個人ログインへの変更は、2台限定・ログイン不要の要求を満たさないため採用しない。WARP/Mac常時稼働への回帰も導入・保守を増やすため採用しない。

## 実装と受入

実AIとモックを明示的に分け、実AIは専用project・DB/schema・非公開bucket・固定入口・元期限を照合する。API送信前記録、同一操作ID、予算予約、自動再送禁止、Responsesのstore:falseを維持する。会話・入力写真・管理資格情報を共用端末へ永続保存しない。

自動試験、実クラウドの拒否試験、Macの実AI操作、Windows本人による取込・接続を別に記録する。証明書発行やモックの合格を、Windowsで基本4機能が使えた証拠へ流用しない。実測と残件は[実AI試用準備報告](../live-trial-preparation-20261020.md)を参照する。

追加契約、入金、予算増額、期限延長、既存業務DBとの接続は今回の許可に含めない。VoiceOverとChromeのPDFコピー空白問題は保留を継続する。
