# ADR-0018: POPの文字指定を説明し、定型を補うデザイン希望を設ける

日付: 2026-10-23
状態: 採用（ローカル実装・無課金検証済み。既存3台限定試用版への反映をユーザー承認、配備前確認中）
関連: REQ-003 / REQ-006 / REQ-007 / REQ-009 / REQ-010 / REQ-011

## 判断

ユーザーは、提案画面で見出し・キャッチコピーを選ぶ効果と、選ばない場合の扱いを分かるようにしたいこと、4種類の配色・構図だけで似たPOPになりがちなためカスタマイズ性を持たせたいことを示した。

見出し・コピーを任意の追加文字指定として説明し、「入れない」を選んでも元の商品情報を削除しないことを明示する。掲載文は入力行と許可済みの中立見出しの範囲を維持し、自由な商品特徴の追加や言い換えへ拡張しない。

簡単に選べる4種類の定型を残し、定型を使わない自由指定と最大500文字のデザイン希望を追加する。希望は色・余白・配置・装飾などの調整に使い、商品情報・価格・用紙・掲載文字を変更する経路にしない。デザインの希望とベース選択は下書きに保持し、編集後は画像送信を再確認する。

## 理由と代替案

定型だけを増やす方法は選択肢の管理と似た表現への制約が残る。希望の自由入力を定型に追加すれば、初心者の簡単な操作を維持しつつ、具体的な色や配置を伝えられる。自由指定では定型自体も外せるため、ベースの色に拘束されない。

自由な掲載文の編集や要素別編集を同時に追加する方法は、未入力情報の混入防止と現在の生成中心フローの範囲を広げるため、今回には含めない。個別編集・再利用を後から改善するREQ-007を維持する。

## 維持する条件と限界

用紙4種類、掲載文の元情報検査、送信前の確認・記録、費用・未確定保護、3台限定と従業員ログイン不要を維持する。元の累計10 USD・元期限・未確定3件0.45 USDを変更しない。

ユーザーはローカル結果の確認後、今回の改善を既存3台限定試用版へ反映することを明示承認した。追加AI実行・課金は行わず、認証条件・予算・期限を変更しない。追加契約・AI実行や公開範囲拡大の許可へ広げない。配備と更新後の確認結果は[反映報告](../pop-release-20261023.md)に分離する。

画像モデルの指示遵守と完成デザインの品質は実AI未検証で、人による完成画像の確認を必要とする。試験・実装状態・未実施項目は[改善報告](../pop-proposal-customization-20261023.md)へ集約する。
