## 目的と実施範囲

オレンジ系の定型を選んだ状態で、青・白の希望を追加し、実際の画像で追加指定が配色へ反映されるかを1回だけ観察した。定型を「自由に指定」へ変えると競合条件がなくなるため、オレンジ系のベースを維持する操作を案内した。ただし送信payloadと実際の選択状態は独立して観測できていない。

既存の3台限定試用アプリで、提案1回とPOP画像1枚を作成する手順を案内した。ユーザーは「提案の確認画面まで進んだ」「生成して画像を保存できた」と報告し、保存画像を独立して確認した。既存アプリの固定モデル設定・サーバー側台帳・予約精算・未確定保護を使用する試験で、別の画像生成ツールや別予算による代行はしていない。追加の生成・再生成は実行していない。

Macの専用Chrome別プロセスへ操作ツールを接続できないため、ユーザーの実操作で進めた。操作の本人報告、生成物の目視、台帳の読取結果をそれぞれ区別して記録する。実AI操作はこの本人操作による提案・画像生成であり、確認のための追加AI呼び出しは行っていない。認証・権限・予算・期限・課金設定も変更していない。

## 固定する入力

準備した非公開下書き`/private/tmp/yamadaya-pop-blue-trial-20261023.json`の内容を基準にする。下書きは次のダミー情報とデザイン指定を含み、参照写真を含まない。

| 項目 | 条件 |
|---|---|
| 用紙 | A4縦（`a4p`、210×297mm） |
| 雰囲気 | 明るく |
| 配色・構図のベース | 明るいオレンジを使い、大きな見出しで目を引くデザイン。 |
| 見出し・コピー | 見出し「試験用りんご」、コピー「入れない」を案内。実際の選択状態と送信payloadは独立未観測 |
| 参照写真 | 下書きには含めていない。今回は写真の忠実な保持・編集を検証する条件ではない |

商品情報は次の3行を使用する。「1個」と「198円」の間は半角空白1文字で、行の間は入力改行である。

```text
試験用りんご
1個 198円
表示確認用の架空商品です
```

デザインの希望は次の文字列とする。

```text
配色は青と白を主役にしてください。背景は青、文字は白と濃紺にし、オレンジ色の背景・装飾・帯は使わないでください。りんごは自然な赤色の見た目にしてください。
```
