# 試用版の要求と受入条件

2026-10-20 最新の限定試用（[判断の正本](decisions/ADR-0015-two-device-live-trial.md)）：Mac＋会社Windows 1台で基本4機能の実利用を優先する。2台限定・従業員ログイン不要・元の合計10 USD・未確定3件/0.45 USD・2026-10-26 08:47:54 JSTまでを維持。旧localの凍結と台帳の一度限りの移行により予算を二重にしない。会社PCに管理者のChatGPT/Codex・個人Googleアカウントを追加せず、公開CSR/公開証明書のみを渡す。新しい未確定で再停止し、元処理は再送しない。[実結果と未合格項目](live-trial-preparation-20261020.md)を参照。以下の初期ローカル範囲は履歴。


最新配信方針の正本は親案件の `docs/decisions/ADR-0014-hosted-shared-trial.md`。公開リポジトリでは本書の試用要件と[公開準備報告](hosted-preparation.md)で判断・結果を確認できる。Vercel＋Supabase＋端末認証でMac常時稼働を不要にする。下記ローカル試用の過去合格を、クラウド/2台の新たな合格へ流用しない。

2026-10-19最新の範囲拡張：Web検索を含む基本4機能を使える状態にし、このMacと会社共用PC1台（Windows 11 / Chrome）だけで1週間試す。日常の個人ログイン不要、重要情報の隔離、10ドル上限、未確定0.45ドル保留、同入力再送禁止/新しい未確定で停止を維持する。[最新の結果と残件](all-features-week-trial.md)を正本とし、以下のこのPCだけの受入完了は当時の範囲として保持する。2端末の認証・失効・迂回拒否・HTTPS・Windows操作は、新たな受入条件であり未合格。Wix DNS全体の移行や追加課金を暗黙に承認されたものとしない。

2026-10-19更新。ユーザーが指定した試用版の範囲です。過去の検証履歴や会話を、本番仕様の承認と混同しません。

最終目的は、2店舗・約50名が日常業務で使える会社専用のAI基盤です。今回はAIアプリに不慣れな従業員も気軽に使える基本4機能を優先します。共用PCの個人ログイン不要、入力してから提案を確認するPOP制作、費用の会社管理は維持する重要方針です。個人アカウントの選択発行、高度機能、要素を再編集できるPOP、業務システム連携は将来構想で、今回の試用に実装済みとは扱いません。

利用先について、ユーザーは「一旦このPCで試しに使えれば問題ない」と明示しました。今回の受入対象は、このPCのブラウザから利用するローカル試用です。クラウド公開や別PCへの配備は今回の完了条件に含めません。秘密を除いたソースのGitHub公開は実施済みです。

| ID | 要求 | 受入条件 |
|---|---|---|
| TRIAL-01 | 共用PC用Webアプリ | 個人ログイン画面なし。このPCの127.0.0.1から利用し、基本4機能を選べる |
| TRIAL-02 | 非AI利用者向け | 日本語の操作名、入力例、確認してから送信、コピー・保存・利用終了を提供 |
| TRIAL-03 | 白いLiquid Glass | 半透明の白いパネル、背景のぼかし、やわらかい影。装飾的なキャッチコピーを入れない |
| TRIAL-04 | アニメーション・スケルトン | 画面・カード・ダイアログ・処理待ちに実装。動きを減らす設定を尊重 |
| TRIAL-05 | 重要情報の隔離 | 顧客/従業員/業務DB、社内ファイル、管理APIを接続しない。未知の権限をサーバー側で拒否 |
| TRIAL-06 | 実AIの試用 | 承認済みの専用キー・予算・再開許可の範囲で実行。見本を実AIの結果と偽らない |
| TRIAL-07 | 費用と障害 | 送信前記録、予算予約、二重実行防止、課金未確定の保持、自動再送禁止 |
| TRIAL-08 | POPの流れ | 商品情報・雰囲気・用紙→提案確認→全体画像→保存。写真参照にも対応 |
| TRIAL-09 | POPの用紙・特徴 | A4/A3縦横の入力を固定。提案には未入力の特徴を自動採用しない |
| TRIAL-10 | 保存 | 文章・画像・画像型PDFのダウンロード、POP下書きのJSON保存と復元 |
| TRIAL-11 | 検証 | 実ブラウザで操作。自動・モック・実AI・未実施の区別を残す |
| TRIAL-12 | GitHub | 秘密・実行データを含めないソースを公開。技術選定理由を残す |

個別アカウント・高度機能・本番業務連携・一般公開の無認証AI APIは対象外。将来、別PCやクラウドへ配備する場合は、端末認証と権限境界を別途検証します。

実AIの利用は承認済みの合計10 USD以内に限定します。2026-10-18には未確定2件/$0.40を保留した再開が承認されました。その後の追加の未確定を受け、2026-10-19の最新指示では、3件/$0.45を保留し、Web検索を停止したまま他の基本機能を再開することが承認されています。AIチャットはWeb検索なしで提供し、POP作成・画像作成/修正・文章作成を維持します。Web検索の恒久的な要求撤回や解決済み判定にはしません。

当初の専用キーと許可期限（2026-10-19 09:37、日本時間）を変えず、3件のID・予約額・未確定状態を保持します。同じ未確定入力を再送せず、新たな未確定や期限切れで再停止します。請求照合は継続事項ですが、保留を維持した今回の承認範囲の初期試用を妨げる条件にはしません。再開設定後の実ブラウザで、AI接続・検索無効・元のPOP入力と用紙/雰囲気の復元・提案ボタンの有効化を確認しました。この再開確認に追加の有料API実行はありません。現在の詳細は[運用状態](operations.md#今回の試用状態)を参照してください。
