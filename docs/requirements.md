# 試用版の要求と受入条件

2026-10-18時点。ユーザーが指定した試用版の範囲です。過去の検証履歴や会話を、本番仕様の承認と混同しません。

| ID | 要求 | 受入条件 |
|---|---|---|
| TRIAL-01 | 共用PC用Webアプリ | 個人ログイン画面なし。同じPCから起動し、基本4機能を選べる |
| TRIAL-02 | 非AI利用者向け | 日本語の操作名、入力例、確認してから送信、コピー・保存・利用終了を提供 |
| TRIAL-03 | 白いLiquid Glass | 半透明の白いパネル、背景のぼかし、やわらかい影。装飾的なキャッチコピーを入れない |
| TRIAL-04 | アニメーション・スケルトン | 画面・カード・ダイアログ・処理待ちに実装。動きを減らす設定を尊重 |
| TRIAL-05 | 重要情報の隔離 | 顧客/従業員/業務DB、社内ファイル、管理APIを接続しない。未知の権限をサーバー側で拒否 |
| TRIAL-06 | 実AIの試用 | 別途承認された専用キー・予算内で実行。見本を実AIの結果と偽らない |
| TRIAL-07 | 費用と障害 | 送信前記録、予算予約、二重実行防止、課金未確定の保持、自動再送禁止 |
| TRIAL-08 | POPの流れ | 商品情報・雰囲気・用紙→提案確認→全体画像→保存。写真参照にも対応 |
| TRIAL-09 | POPの用紙・特徴 | A4/A3縦横の入力を固定。提案には未入力の特徴を自動採用しない |
| TRIAL-10 | 保存 | 文章・画像・画像型PDFのダウンロード、POP下書きのJSON保存と復元 |
| TRIAL-11 | 検証 | 実ブラウザで操作。自動・モック・実AI・未実施の区別を残す |
| TRIAL-12 | GitHub | 秘密・実行データを含めないソースを公開。技術選定理由を残す |

個別アカウント・高度機能・本番業務連携・一般公開の無認証AI APIは対象外。別PC/クラウドでの端末認証は別途検証が必要です。
