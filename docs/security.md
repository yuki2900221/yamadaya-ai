# 共用PCの権限とデータ境界

## 利用者

Web利用者はsharedという一種類の権限だけです。画面・APIとも、chat / writing / pop / image以外を拒否します。ブラウザに管理者キーや業務DBの認証情報を渡しません。AIには社内ファイル、顧客・従業員データ、任意のURL取得、コード実行、MCP、シェル、管理ツールを付与しません。Web検索を使う場合だけ既定の検索ツールを付与します。

設定や予算の変更、課金不明の処理の確認は、このPCで行う管理作業です。管理用Web APIはありません。ログイン画面を省くことは、すべての操作を匿名で許可する意味ではありません。

## 入口

サーバーは127.0.0.1だけで待ち受け、接続元・Host・Originを確認します。APIはHttpOnly/SameSiteセッション、送信時はOriginとCSRFを検証。未知のルート、パストラバーサル、過大な入力、未知の機能・権限・モデル等を拒否します。静的配信はビルド済みのHTML・マーク・assetsだけです。開発サーバーを外部公開しません。

端末を制限したリモート利用はこの実装だけでは成立しません。クラウドで使う場合は、認証ゲートウェイや端末証明書等を別途実装・検証し、直接URLからの迂回も拒否する必要があります。接続元ヘッダーの自己申告を信用する変更や0.0.0.0への単純な変更はしません。

## データ

- 会話・入力・参照画像・結果：利用中のブラウザ/サーバーのメモリだけ。
- 費用台帳：サーバー専用SQLite。セッションのハッシュ、操作ID、処理種別、状態、費用等。会話本文や画像を費用台帳へ保存しない。今後の数値使用量と安全なエラー種別は同じ非公開領域へ保存し、本文や秘密を記録しない。
- 利用終了/15分の無操作：セッションと結果を無効化。ダウンロード済みファイルは利用者の管理となる。
- 下書き：利用者が明示的にJSON保存。写真は保存せず、復元時に再選択。
- APIキー：サーバー専用の非公開ファイルまたは環境変数。Git対象外。フロント用VITE_変数に入れない。

AI結果はReactのテキストとして表示し、HTMLとして挿入しません。出典URLはHTTPSだけに制限し、外部タブはnoopener/noreferrer。生成画像はサーバーが指定した画像APIの応答だけです。

## 障害と費用

送信前に排他的なトランザクションで操作と費用枠を保存します。同一IDの二重実行をせず、別の内容へのID再利用も拒否。APIエラー・通信切断・途中応答・未知のモデル/ツール・費用不明を自動再送しません。プロセス再起動時のsendingはunknownとし、新規送信を止めます。

予約額は内部制御です。プロバイダーの請求額や請求確定を保証せず、usageによる計算と請求未照合を区別します。キー失効やサービス側障害時に、他プロジェクト・本番キー・上位モデルへ切り替えません。

## 限界

この試用は会社の本番セキュリティ審査や侵入試験の代替ではありません。OS管理者や同じOSアカウントでファイル操作できる人、悪意ある拡張機能、利用者自身のダウンロード保存、実商品情報の真実性やAI画像の文字・外観まで保証しません。データ保存を追加する際は要求・保持期間・権限・削除を再設計します。

現在のローカルキーの0600は、同じOSユーザーとしてシェルやファイルを操作できる利用者との分離にはなりません。実店舗へ渡す際はキーを共用ブラウザのOS権限から分離したサーバーへ置くか、OSの利用制限を別途検証します。今回の10ドル制御は本アプリの台帳による制御であり、キーを持つ人がアプリ外で直接APIを呼ぶ場合の上限を保証しません。
