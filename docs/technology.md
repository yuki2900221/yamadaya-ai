# 技術選定

新しいVercel＋Supabase準備の選定理由は[公開準備報告](hosted-preparation.md#実装選定理由)へ集約。下記の単一PC/SQLiteは既存ローカル試用の説明で、クラウド台帳の採用ではない。

試用版の選定であり、会社全体や本番方式の決定ではありません。やまだやAI共通原則v0.1にある、サーバー側認可、開発/本番分離、最小権限、差替え可能な外部AI境界、予算と未確定処理、検証の正確な報告を適用します。

| 採用 | 理由 | 比較した代案・制約 |
|---|---|---|
| React 19.3.1 / React DOM | 既存検証の固定依存を再利用。4機能の入力・結果・画面状態を分け、利用終了でまとめて破棄できる | 素のHTML/JSは初期依存が少ないが、複数機能の状態・中断・復元を一貫して扱いにくい。Next.js等のフルスタック構成は現段階では不要 |
| Vite 8.3.4 | 既存の固定依存。軽いビルドと開発更新ができる | 開発サーバーは試用配布用にしない。配信はNodeでビルド成果物だけに限定 |
| Node.js 24系のHTTPサーバー | 外部APIのキーと予算・認可をブラウザから分離。公開ルートを小さな許可リストで管理できる | フレームワーク依存を減らせる一方、入力・Origin・CSRF・サイズ制限等を明示実装してテストする必要がある |
| Node内蔵SQLite | 送信前の永続記録と排他トランザクション、再起動後の未確定保持。外部DB契約を増やさない | 単一PC・単一サーバープロセスの試用向け。複数インスタンス運用には共有DB/キューを別途検証 |
| サーバー専用の基本4機能 | ブラウザにadmin権限を渡さず、顧客・従業員DBやファイル操作の経路自体を作らない | UIで隠すだけの権限制御は採用しない。高度機能は今回の範囲外 |
| 一時セッション / HttpOnly / SameSite=Strict / CSRF | 個人ログインなしで利用ごとのデータを分離。外部サイトからの送信や別セッションの結果取得を拒否 | 個人識別の代替ではない。OSの管理者や共有したダウンロードフォルダまで隔離するものではない |
| ブラウザ/サーバーのメモリ | 共用PCに会話を永続保存しない。終了・期限で消去 | サーバー再起動後の回答・画像回収はできない。費用台帳は別に保持 |
| CSSの半透明・backdrop-filter・影 | 白いLiquid Glassを画像や巨大なUIライブラリなしで表現。ぼかし未対応時も白い背景で読める | Apple固有コンポーネントそのものではなく、Webでの表現。コントラストを確保する必要がある |
| CSSのtransition / animation | カード、画面、待機、ダイアログに動きを統一。外部アニメーション依存を追加しない | 複雑な物理演算は不要。OSの動きを減らす設定とアプリ内の抑制に対応 |
| スケルトン表示 | 初期取得とAI待機を画面と同じ構造で示す。待機中は重複送信を無効化 | スケルトンは成功や進捗率の保証ではない。取消後もAPI処理が続く可能性を表示 |
| 自作のSVGアイコン | 必要な操作だけで揃え、外部アイコン/画像配信を不要にする | 狭い画面で文字を隠してもaria-labelを維持 |
| OpenAI Responses / GPT-6 Luna | 前段の検証で日本語提案と低コストを確認した固定モデル。store:false、ツール許可制、出力上限を指定 | 最終採用ではない。実試用で品質を評価し、勝手なモデル切替はしない |
| Images / GPT-Image-2.5 Flare固定版 | 前段でPOP全体画像と写真参照を確認したモデルを維持 | 画像中の日本語・細部の再現を保証しない。価格・商品外観は利用者が確認する |
| Web検索はチャット内で任意 | 不要な検索費用を避け、出典をHTTPSリンクで表示。1処理のツール呼出しを制限 | 社内ファイル検索や任意の外部連携は提供しない |
| ブラウザ内の画像縮小・JPEG化 | 参照画像のサイズと送信量を制限し、EXIF等を再描画で除く | 権利・人物・機密の検出を保証するものではない |
| 画像を直接埋め込むPDF | 4種類の用紙実寸を固定し、サーバーのファイルアクセスや有料PDFサービスを増やさない | JPEGの実AI結果は元バイトを使用。文字選択・日本語フォント埋込みは画像型の対象外。PNG/SVGは同画素数でJPEG化（品質0.96）。PNGの可逆性は維持しない |
| Node標準のテスト | 費用・権限・障害を偽の外部応答で再現し、追加課金を防ぐ | 自動試験と実ブラウザ・実AIの試験は分けて報告 |

公開用に新しい技術へ統一するだけの理由で、既存POPアプリ・業務システム・認証基盤は変更しません。Cloudflare等での端末認証・クラウド配備は別の境界であり、このローカル試用の合格へ含めません。
