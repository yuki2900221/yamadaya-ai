## 自動・内部検査

`npm test`：45件合格、失敗0。外部APIは偽の応答で検証し、課金しない。

権限外ルート、接続元/Host/Origin/CSRF、セッション分離、終了/無操作期限、送信前台帳、重複/競合、費用上限、再起動時の未確定、モデル/ツール/応答制限、画像確認、送信形式、費用計算、1回だけの承認例外、非公開ファイルの配信拒否、PDF構造を対象にした。

`npm run build`：成功。公開許可リストの秘密検査も実施する。公開ファイルだけを別フォルダへコピーし、依存の再インストール（npm ci --offline --ignore-scripts）・45件の試験・ビルド・秘密検査も成功した。当初のローカル依存へのリンクを含むlockをこの検査で発見し、レジストリから独立再現できるlockへ修正した。

PDF生成関数をブラウザと共有し、ダミー画像でA4/A3縦横の4PDFを生成。pypdf/pdfplumberで実寸・余白・画像バイトを検査、Popplerで4件を描画して目視確認した。寸法誤差0.00001mm未満、最小余白は丸め誤差内で5mm、JPEG埋込みバイトは一致。これはCLI生成の内部検査であり、ブラウザから保存したファイルの一致や、編集要素の位置ずれ1mm以内の再測定ではない。
